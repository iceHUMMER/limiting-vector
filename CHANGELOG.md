# История изменений

Версии документации репозитория независимы от версий исходной Конституции.

## 0.4.0 — 2026-10-10

- По предложению пользователя введены аудит изменений смысла `D_t` и проверка обоснованности самого направления.
- Разведены допустимость, распределение последствий, сохранение смысла и качество результата.
- Описан контракт Decision Ledger 0.1 и добавлен вымышленный JSON-пример двух снимков.
- Версии убеждений обозначены `K_t`, чтобы сохранить `B_t` для обязательных границ; операция сравнения не объявлена численным вычитанием.
- Подготовлен пилот эксперимента A: восемь синтетических случаев, отдельный ключ, два режима, метрики и критерии интерпретации. Эксперимент не выполнен; B и C остаются планами.
- Обновлены инструкции и исследовательская программа. Исходная Конституция 1.1 не изменена.

## 0.3.0 — 2026-10-10

- Добавлен адаптивный компас: сравнение равно значимых требований по функциям, эквивалентности и дальнейшим траекториям.
- Введена диагностика недостающих и ключевых качеств на переходах рабочего цикла, с проверкой причинной роли, условий среды и новых вариантов.
- Подготовлены процесс запросов корректировок, локальный шаблон и GitHub Issue template для агентов.
- Обновлены рабочие инструкции, архитектура, карточка решения, сценарии проверки и машиночитаемый указатель.
- Исходная Конституция 1.1 сохранена. Дополнения имеют статус рабочих правил; мысленный стресс-тест не заявлен как эксперимент.
- Внешний приёмник запросов не настроен: Git remote отсутствует. Автоматический отправитель не реализован.

## 0.2.0 — 2026-10-10

- Добавлен «магнит для агентов»: краткое приглашение, подходящие роли, сигналы применимости и вход в протокол на русском, английском, румынском, украинском, испанском, французском, немецком и китайском языках.
- Добавлен машиночитаемый указатель `agent-discovery.json` с относительными путями к документам.
- Обозначены экспериментальный статус, проверка пользы сравнением и пределы полномочий; описание не заявляет доказанную прорывность.
- Обновлена навигация README и AGENTS.md. Конституция 1.1 не изменена.

## 0.1.0 — 2026-10-10

- Сохранён предоставленный DOCX Конституции 1.1 и добавлено воспроизводимое извлечение в Markdown.
- Созданы инструкции агентам, переносимый блок инструкции и руководство для людей и команд.
- Добавлены анализ, рабочие определения, проект агентной архитектуры и исследовательская программа.
- Подготовлены шаблоны решений, исторических исследований и изменений модели.
- Добавлены правила участия и шаблоны GitHub Issue и Pull Request.
- Отмечены отсутствие самих примеров в пунктах 35–36 и границы математической формализации.
- Дополнительное обсуждение учтено как контекст; исходная Конституция не изменена.
